Who we are

Six Stars Media ("Seis Estrellas" / "Six Stars") is operated by an individual. Contact: seisestrellas.media@gmail.com.

What the application does

"Six Stars CLI" is an internal command-line tool used only by its operator. It uploads short videos to the operator's own two YouTube channels and reads those channels' own data. It has no public interface and no third-party users, and it does not collect any data from viewers or from other YouTube users.

YouTube API Services

This application uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

The application requests these OAuth scopes, only for the operator's own channels:

  • youtube.upload: upload Shorts to our own channels.
  • youtube.readonly: confirm which of our channels a login belongs to, so a video is never uploaded to the wrong channel, and read our own videos' metadata.
  • yt-analytics.readonly: read our own channels' performance (views, retention) to decide what to publish next.

With an API key (no user data) the tool also reads public YouTube search results and video view counts, to check whether a moment has already been widely covered.

What data we store and how

  • OAuth tokens are stored only on the operator's computer, are never shared, and are never committed to source control.
  • Our own channels' video IDs and performance metrics are stored in a local database on the operator's computer, only to evaluate our own content.
  • We do not sell, share, or transfer any data obtained through YouTube API Services, and we do not use it for advertising.

Retention and deletion

Data obtained through YouTube API Services is kept only while it is needed to operate our channels. Stored tokens are deleted when access is revoked, and stored data is deleted within 30 days of a request sent to the contact address above.

How to revoke access

Access can be revoked at any time from Google security settings (third-party access).

Cookies

This website uses no cookies and no analytics.
